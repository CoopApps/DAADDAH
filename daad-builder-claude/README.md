# DAAD Builder - Claude Integrated Edition

**Build text adventure games by talking to Claude Desktop!**

---

## ⚡ Quick Start (2 Steps)

### 1. Start the App

Double-click:
```
quick-start.bat
```

Wait for: `🚀 DAAD Builder MCP API server starting on http://localhost:3456`

### 2. Use Claude Desktop

Restart Claude Desktop, then say:
```
Create a mysterious forest location with ancient twisted trees
```

**Watch it appear in the app instantly!** ✨

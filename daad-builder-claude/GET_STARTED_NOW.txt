========================================
TROUBLESHOOTING
========================================

If Node.js not found:
- Check D:\nodejs\node.exe exists
- Check D:\nodejs\npm.cmd exists

If Cargo not found:
- Check D:\.cargo\bin\cargo.exe exists

If dependencies fail:
- Run: setup-environment.bat
- Then manually: npm install

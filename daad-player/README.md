# DAAD Standalone Game Player

A standalone executable for playing DAAD text adventure games created with the DAAD Builder.

## Features

- ✅ Loads games from JSON files (exported from DAAD Builder)
- ✅ Full text adventure gameplay
- ✅ Cross-platform (Windows, macOS, Linux)
- ✅ No dependencies - single executable
- ✅ Drag-and-drop game files onto executable
- ✅ Console-based interface

## Building

### Windows
```bash
cargo build --release
```

The executable will be at: `target/release/daad-player.exe`

### macOS / Linux
```bash
cargo build --release
```

The executable will be at: `target/release/daad-player`

## Usage

### Method 1: Drag and Drop
Simply drag a `.json` game file onto the `daad-player` executable.

### Method 2: Command Line
```bash
daad-player mygame.json
```

## Supported Commands

### Movement
- `NORTH` / `N` - Go north
- `SOUTH` / `S` - Go south
- `EAST` / `E` - Go east
- `WEST` / `W` - Go west
- `UP` / `U` - Go up
- `DOWN` / `D` - Go down
- `NORTHEAST` / `NE` - Go northeast
- `NORTHWEST` / `NW` - Go northwest
- `SOUTHEAST` / `SE` - Go southeast
- `SOUTHWEST` / `SW` - Go southwest
- `IN` - Go in
- `OUT` - Go out
- `GO [direction]` - Move in a direction

### Actions
- `LOOK` / `L` - Look around current location
- `INVENTORY` / `INV` / `I` - Check your inventory
- `EXAMINE [object]` / `X [object]` - Examine an object
- `GET [object]` / `TAKE [object]` - Pick up an object
- `DROP [object]` - Drop an object

### System
- `QUIT` / `EXIT` - Exit the game

## Creating Game Files

Use the **DAAD Bevy Builder** to create games, then:

1. Save your project (Ctrl+S) - creates a `.json` file in `exports/`
2. Give that `.json` file to players along with this executable
3. Players can drag-drop the `.json` onto the executable to play

## Distribution

To distribute your game to players:

1. Build the player executable for target platform
2. Include your game's `.json` file
3. Optional: Create a batch file/shell script to auto-launch:

**Windows (play.bat):**
```batch
@echo off
daad-player.exe mygame.json
pause
```

**macOS/Linux (play.sh):**
```bash
#!/bin/bash
./daad-player mygame.json
```

## File Format

The player loads `.json` game files with the following structure:
```json
{
  "title": "My Adventure",
  "author": "Your Name",
  "version": "1.0",
  "locations": [...],
  "objects": [...],
  "rules": [...],
  "flags": [...],
  "messages": [...]
}
```

These files are automatically generated by the DAAD Builder when you save your project.
